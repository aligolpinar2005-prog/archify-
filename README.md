# Archify 🚀

Archify, herhangi bir programlama dilinde yazılmış kaynak kodları otomatik olarak analiz eden, Arch Linux paket şablonları (`PKGBUILD`) üreten ve bunları doğrudan kurulabilir yerel paketlere dönüştüren ya da **AUR (Arch User Repository)** depolarına otomatik yükleyen akıllı bir CLI otomasyon aracıdır.

---

## ✨ Özellikler

* **🔍 Akıllı Dil ve Derleyici Tespiti:** Kaynak kod dizinindeki kritik dosyaları (`Cargo.toml`, `CMakeLists.txt`, `go.mod`, `setup.py`, `package.json` vb.) otomatik tarayarak uygun derleme ve paketleme adımlarını kendisi belirler.
* **🏷️ Otomatik Git Sürüm Yakalama (`git describe`):** Sürüm belirtilmediğinde Git tag ve commit geçmişinden otomatik olarak Arch standartlarına uygun dinamik sürümler (Örn: `1.0.0.r4.g2a1b`) türetir.
* **🌐 Uzaktan Erişim ve Repo Desteği:** Yerel dizinlerin yanı sıra doğrudan GitHub repo bağlantılarını veya `.tar.gz`, `.tar.xz`, `.zip` uzaktan arşiv linklerini girdi olarak kabul eder.
* **🛡️ SHA256 Otomatik Hesaplama:** Harici kaynak arşiv dosyalarını otomatik indirerek `sha256sums` bütünlük doğrulama kodlarını milisaniyeler içinde hesaplar ve `PKGBUILD` içine gömer.
* **📦 Gelişmiş Bağımlılık Analizi:** Kaynak koddaki kütüphane çağrılarını (`openssl`, `zlib` vb.) analiz edip `pacman` bağımlılık listesine akıllıca ekler.
* **✍️ Canlı PKGBUILD Düzenleme:** Paket inşa edilmeden veya AUR'a gönderilmeden önce üretilen `PKGBUILD` dosyasını sistemin varsayılan editörü (`nano`, `vim` vb.) ile düzenleme imkanı sunar.
* **🐋 İzole Chroot Derleme Desteği:** `--use-chroot` parametresiyle, sistem kirlenmesini önlemek için paketi tamamen izole bir temiz Arch kök dizini (Chroot) içinde derler.
* **🚀 Doğrudan AUR Entegrasyonu:** `--push-aur` parametresi ile paketleri otomatik olarak AUR depolarına gönderir, `.SRCINFO` dosyasını sizin yerinize oluşturur ve Git push işlemlerini tamamlar.
* **📝 Günlük Dosyası (Logging):** Tüm analiz, derleme süreçlerini ve hataları zaman damgalı olarak `archify.log` dosyasına kaydeder.

---

## 🛠️ Desteklenen Teknolojiler

Archify şu an aşağıdaki yapıları ve dilleri yerleşik olarak tanır:
* **Rust** (`Cargo.toml`)
* **Go** (`go.mod`)
* **C / C++** (`CMakeLists.txt` veya standart `Makefile`)
* **Python** (`setup.py` veya `pyproject.toml`)
* **Node.js** (`package.json`)

## 📦 Kurulum

Archify'ı kendi bilgisayarınıza bir Arch Linux paketi olarak kurmak için:

1. Bu depoyu klonlayın:
   ```bash
   git clone https://github.com/kullanici/archify.git
   cd archify
   ```

2. `makepkg` komutu ile sistemi derleyin ve yerel paket yöneticinizle kurun:
   ```bash
   makepkg -si
   ```

## 🎮 Kullanım Rehberi

Sisteme kurulduktan sonra `archify` komutunu terminalden doğrudan çağırabilirsiniz.

### 1. Yerel Paket Üretme (Local Build)
```bash
archify /path/to/source_code --name uygulamam --ver 1.2.0
```

### 2. GitHub Reposunu Doğrudan Paketleme
```bash
archify https://github.com/user/repo-adi --name paket-adi
```

### 3. İzole Chroot Alanında Derleme
```bash
archify /path/to/source_code --use-chroot
```

### 4. Doğrudan AUR'a Yükleme (AUR Deploy)
```bash
archify https://github.com/user/repo-adi --push-aur
```
*(Not: AUR yüklemeleri için bilgisayarınızda SSH anahtarlarınızın `aur.archlinux.org` üzerinde tanımlı olması gerekir).*

## ⚙️ Parametreler

| Parametre | Açıklama | Varsayılan |
| :--- | :--- | :--- |
| `source` | Paketlenecek kaynak kod yolu, repo URL'si veya tarball linki *(Zorunlu)* | - |
| `--name` | Üretilecek paket adı | Klasör adı |
| `--ver` | Paketin versiyon numarası | Git tag/1.0.0 |
| `--push-aur`| Paketi doğrudan AUR'a pushlar | Aktif değil |
| `--use-chroot`| Paketi izole temiz chroot alanında derler | Aktif değil |
